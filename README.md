CVS AUTOMOTIVE — Polished Landing Page
======================================

GitHub Pages (recommended free permanent host)
----------------------------------------------
1. Create a new public GitHub repository (e.g. "cvs-automotive")
2. Upload this index.html file
3. Go to Settings → Pages → Source: Deploy from a branch → main / root
4. Your free URL will be:
   https://YOUR-USERNAME.github.io/cvs-automotive/

Netlify Drop (fastest temporary)
--------------------------------
1. Go to https://app.netlify.com/drop
2. Drag this folder onto the page
3. You get a free URL instantly
